# **App Name**: Infinite

## Core Features:

- Direct Chats: Create and join one-on-one direct chats for instant communication.
- Group Discussions: Manage and participate in group discussions with multiple members.
- Broadcast Channels: Follow and create broadcast channels to share updates with a large audience.
- User Statuses: Set or view user statuses to indicate availability or current activity.

## Style Guidelines:

- Primary color: Vibrant orange (#FF8C00) to represent energy and immediacy.
- Background color: Warm gray (#FAEADA) for a soft, neutral backdrop that complements the orange.
- Accent color: Coral (#FF8080), an analogous hue to orange but contrasting enough to highlight interactive elements.
- Body and headline font: 'PT Sans' (sans-serif) for readability and a modern touch.
- Use clean and simple icons that clearly represent different actions and functionalities.
- Employ a clean and intuitive layout for easy navigation and a seamless user experience.
- Incorporate subtle animations for transitions and interactions to enhance user engagement.
